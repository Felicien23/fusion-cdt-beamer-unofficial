# Logo folder

The theme expects `fusion-cdt-logo-white.pdf` here. The file is not part of the
repository: run `make logo` (or `sh scripts/fetch-logo.sh`) from the repository root
to download it. See [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) for why,
and the README section [Logo](../../README.md#logo) for doing it by hand.
